# docs/vision/

Early vision documents — the long-term picture of what JARVIS could become.

**These describe aspirations, not the current implementation.** Several components
they mention (multi-link Wi-Fi pose estimation, vital-sign sensing from radar, a
large knowledge graph) were later evaluated and either re-scoped or dropped as
physically or practically infeasible on this hardware. The reasoning is recorded in
[`../DECISIONS.md`](../DECISIONS.md).

For what actually exists and works, see the root [`README.md`](../../README.md).
